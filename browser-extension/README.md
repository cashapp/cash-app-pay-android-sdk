Chrome extension demo: Injects a "Pay with Cash App" button into every page (demo).

Install locally (developer mode):
1. Open chrome://extensions
2. Enable "Developer mode"
3. Click "Load unpacked" and select the "browser-extension" folder in this repo

Notes:
- This is a demo injector; it opens the Cash App Sandbox docs. Replace the click handler to integrate real web SDK or flow.
- Do not publish this with real credentials.
